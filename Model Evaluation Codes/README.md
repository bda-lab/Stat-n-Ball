# Stat-n-Ball Evaluators

This directory contains evaluation scripts for the **PPI**, **CN15K**, and **NL27K** datasets.

The evaluators use the embeddings generated by Stat-n-Ball to compute geometric validity, confidence prediction, and ranking-based evaluation metrics.

## PPI Evaluation

Use `evaluator_ppi.py` for the PPI dataset.

### Usage

```bash
python3 evaluator_ppi.py <test_file> <cls_file> <rel_file> <dataset_dets> <output_file_name>
```

### Arguments

- `test_file`: Path to the file containing the test axioms.
- `cls_file`: Path to the file containing the learned concept/class embeddings.
- `rel_file`: Path to the file containing the learned relation embeddings.
- `dataset_dets`: Dataset identifier or description to include in the evaluation output.
- `output_file_name`: Name or path of the file where the evaluation metrics will be written.

### Example

```bash
python3 evaluator_ppi.py ppi_test.txt ppi_cls_embeddings.pkl ppi_rel_embeddings.pkl ppi output_ppi.txt
```

## CN15K and NL27K Evaluation

Use `evaluator_nl_cn_data.py` for the CN15K and NL27K datasets.

### Usage

```bash
python3 evaluator_nl_cn_data.py <test_file> <cls_file> <dataset_dets> <output_file_name>
```

### Arguments

- `test_file`: Path to the file containing the test axioms.
- `cls_file`: Path to the file containing the learned concept/class embeddings.
- `dataset_dets`: Dataset identifier or description to include in the evaluation output.
- `output_file_name`: Name or path of the file where the evaluation metrics will be written.

### Example: CN15K

```bash
python3 evaluator_nl_cn_data.py cn15k_test.txt cn15k_cls_embeddings.pkl cn15k output_cn15k.txt
```

### Example: NL27K

```bash
python3 evaluator_nl_cn_data.py nl27k_test.txt nl27k_cls_embeddings.pkl nl27k output_nl27k.txt
```

## Evaluation Output

The evaluator scripts write the computed metrics to the specified output file.

Depending on the dataset and available ranking groups, the output may include:

- Good Ball count
- Valid Ball count
- Mean Absolute Error (MAE)
- confidence-error metric reported by the evaluator as `MSE`
- HDMA mean and median
- nDCG mean and median
- number of subconcept groups evaluated

## Notes

The evaluator scripts use **positional command-line arguments**. Provide the arguments in exactly the order shown above.

For example, use:

```bash
python3 evaluator_ppi.py ppi_test.txt ppi_cls_embeddings.pkl ppi_rel_embeddings.pkl ppi output_ppi.txt
```

rather than:

```bash
python3 evaluator_ppi.py --test_file --cls_file --rel_file --dataset_dets --output_file_name
```
